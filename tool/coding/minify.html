HTML · CSS · JS Minifier

HTML 안의 CSS와 JavaScript까지 함께 압축합니다. 파일을 선택하거나 코드를 붙여 넣으세요.

파일을 선택하면 입력창에 즉시 표시됩니다. HTML 파일은 내부 style/script도 함께 압축합니다.

대기 중

주의: 압축은 코드의 동작을 완벽히 보장하지 않습니다. 특히 JavaScript의 문자열·정규식·템플릿 문자열과 HTML의 공백에 민감한 영역은 실제 페이지에서 테스트하세요.

미리보기에서 JavaScript 실행을 허용합니다. 직접 만든 코드만 테스트하세요. 샌드박스 때문에 localStorage 등 일부 브라우저 기능이나 외부 API 요청은 실제 페이지와 다르게 동작할 수 있습니다.
