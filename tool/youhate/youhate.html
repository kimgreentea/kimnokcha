유튜브용 확장 프로그램

적용 전
YouTube
적용 후

설치 방법

1 파일 다운로드

다운로드 버튼을 눌러 youhate.zip을 다운로드

2 압축 풀기

다운로드한 ZIP 파일을 압축 해제

5 번 이후에는 압축 해제된 파일의 경로나 이름을 수정 시 제대로 작동하지 않습니다. 변경하고 싶다면 현재 단계에서 변경합니다.

3 확장 프로그램 페이지 열기

Chrome: → 주소창에 붙여넣기

Edge: → 주소창에 붙여넣기

4 개발자 모드 켜기

Chrome: 오른쪽 상단 개발자 모드

Edge: 왼쪽 하단 개발자 모드

브라우저 재실행 시 개발자 모드를 끄라는 메세지가 나온다면 나중에 버튼 누르기

5 확장 프로그램 불러오기

Chrome: 왼쪽 상단 압축해제된 확장 프로그램 로드

Edge: 오른쪽 상단 압축 풀린 파일 로드

버튼 클릭 후 압축을 풀어 놓은 youhate 폴더를 선택

6 유튜브 새로고침

새로고침 후 적용 확인

설정 변경

Chrome: chrome://extensions → 유튜브 시러의 세부 정보 → 하단 확장 프로그램 옵션

Edge: edge://extensions → 유튜브 시러의 세부 정보 → 하단 확장 옵션
