1 ZIP 파일 다운로드

위의 다운로드 버튼을 눌러 youhate.zip을 다운로드

2 압축 풀기

다운로드한 ZIP 파일을 압축 해제

3 번을 실행한 이후에는 압축 해제된 파일의 경로, 이름 등을 바꿀 수 없어요. 변경하고 싶다면 현재 단계에서 변경해요.

3 확장 프로그램 페이지 열기

Chrome 주소창에 chrome://extensions 입력하여 접속

4 개발자 모드 켜기

오른쪽 위의 개발자 모드 를 켜기

5 압축해제된 확장 프로그램 불러오기

왼쪽 위 압축해제된 확장 프로그램을 로드 누르기

압축을 풀어 놓은 youhate 폴더를 선택 후 확인

저는 Edge예요!

1 ZIP 파일 다운로드

위의 다운로드 버튼을 눌러 youhate.zip을 다운로드

2 압축 풀기

다운로드한 ZIP 파일을 압축 해제

3 번을 실행한 이후에는 압축 해제된 파일의 경로, 이름 등을 바꿀 수 없어요. 변경하고 싶다면 현재 단계에서 변경해요.

3 확장 프로그램 페이지 열기

Edge 주소창에 edge://extensions 를 입력하여 접속

4 개발자 모드 켜기

왼쪽 하단의 개발자 모드 켜기

5 압축해제된 확장 프로그램 불러오기

오른쪽 상단 압축 풀린 파일 코드 누르기

압축을 풀어 놓은 youhate 폴더를 선택 후 확인

6 유튜브 새로고침

유튜브 새로고침하면 쨔잔

설정 변경

Chrome에서는 chrome://extensions → 유튜브 시러의 세부 정보 → 하단 확장 프로그램 옵션

Edge에서는 edge://extensions → 유튜브 시러의 세부 정보 → 하단 확장 옵션
